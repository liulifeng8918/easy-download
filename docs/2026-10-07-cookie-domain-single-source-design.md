# Cookie 授权域名单一来源设计

## 决策

授权域名只由 Chrome 扩展设置页维护。易下载主程序不再要求用户维护第二份域名列表，也不再用隐藏的本地 `domains` 配置拒绝扩展推送。

## 推送协议

扩展每次推送 Cookie 时携带 `X-Easy-Download-Domains` 请求头，值为用户在扩展设置页保存的域名列表。后端验证：

- 域名列表不能为空；
- Cookie 中出现的每个域名必须等于授权域名或属于其子域名；
- 不满足时返回明确的错误码和被拒绝域名，不再只显示 `http-403`。

## 兼容性

旧扩展没有该请求头，后端会返回“请更新连接助手”，避免静默接受未声明的 Cookie。旧的本地 `domains` 配置只保留用于迁移读取，不再作为新的授权来源。

## 用户流程

1. 易下载只负责生成和复制配对令牌。
2. 用户在 Chrome 扩展选项页填写 `douyin.com`、`youtube.com` 等域名。
3. Chrome 授权网站访问权限后，扩展立即推送。
4. 状态页显示“推送成功”或具体失败原因。

- 修复 YouTube 播放脚本解析失败、只取得预览图后被误报“没有所选画质”的问题。
- 新增专用于 YouTube 的官方解析组件 2026.11.23；保留其它平台的原有引擎、Chrome 扩展、代理策略和下载资源预算。

- Python 下载服务已重新打包；不是仅替换旁边的源码。

## 下载与升级

- 新用户：`EasyDownload-1.0.4-x64-portable.zip`，完整解压后双击 `易下载.exe`。
- 已有 1.0.1–1.0.3 用户：退出易下载，将 `EasyDownload-1.0.4-update.zip` 的 `resources` 合并到原目录并覆盖程序文件。保留 `resources/app/user-data`，无需重新连接 Chrome。不要删除整个原目录或同时运行两份程序。
- PDF：`EasyDownload-1.0.4-User-Manual.pdf`，沿用 1.0.2 图文操作手册，操作步骤不变。
- 两个 ZIP 均有 `.sha256` 校验文件。原 1.0.3 发布保留。

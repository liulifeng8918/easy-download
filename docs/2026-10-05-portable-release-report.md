## 使用与限制

完整解压并退出旧版，再双击启动入口。已在同一 Windows 用户下激活的用户沿用原有授权；未激活的用户通过右上角“未激活 · 输入激活码”输入有效激活码。

程序自带 Electron、Python sidecar、yt-dlp 和 FFmpeg，无需另外安装 Node.js 或 Python。设置与激活记录仍存放在用户本机目录；绿色版不是“所有数据只存到解压目录”的数据便携版本。

本机此前的 NSIS 安装器被智能应用控制拦截；本次实际解压 EXE 启动成功。分发 ZIP 没有关闭安全功能、签名文件或绕过系统策略，不承诺其他电脑不会拦截。若直接 EXE 被拦截，不应反复换名称或加壳尝试规避。

启动脚本使用 UTF-8 和 CRLF，并先设置 `chcp 65001`，以避免中文命令被错误解析。

# 链接能力检测与用户提示设计

## 目标

让普通用户只看到“这个链接现在能不能下载、下一步怎么做”，不要求用户了解内部下载引擎或网站名单。

## 运行流程

1. 用户粘贴具体视频播放页并点击开始下载。
2. 本机引擎先做一次不写入文件的链接检测。
3. 检测结果只使用用户语言：可直接下载、需要登录、需要代理、画质不可用、视频不可见、暂不支持。
4. 检测通过后才创建下载任务。
5. 下载结束后检查输出目录是否真的生成了有效媒体文件；没有文件时不能显示成功。

## 兼容组件

针对需要网页脚本挑战的网站，程序优先使用随程序提供的 Node.js 运行时；找不到时再尝试本机 Node.js。若 YouTube 链接没有可用兼容组件，提示用户更新程序，不暴露内部引擎术语。

## 对外支持范围文案

> 易下载会在每次粘贴链接后自动检测当前页面。可直接访问的视频会开始下载；需要登录或代理时，程序会告诉你怎么处理；首页、搜索页、失效链接和暂未适配的页面会明确提示原因。不同网站、不同视频的结果可能不同。

不承诺“所有网站都支持”，也不要求普通用户知道内部解析器名单。

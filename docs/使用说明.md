# 易下载（测试版）使用说明

新手优先阅读：[易下载用户操作手册.md](易下载用户操作手册.md)。本文保留开发者签发、兼容性和高级设置说明。

## 1. 安装与首次启动

运行 `EasyDownload-<版本>-x64.exe`，按安装向导选择目录。安装完成后打开“易下载”。

程序内置 Python 下载引擎，无需另装 Python。仅支持 Windows x64；当前验收以本机环境为准，不代表已完成所有 Windows 10/11 环境测试。

如果显示“Windows 已保护你的电脑／未知发布者”，当前测试安装包尚未配置发行者数字签名。此提示不等同于病毒检出，但也不能据此认定软件绝对安全。若安全中心显示具体威胁名称，请停止运行并把检测名称和文件路径反馈给发行方；不要关闭防护或添加排除项。

## 2. 激活

1. 在主界面右上角点击“未激活 · 输入激活码”，或点击下载区的“立即激活”。应出现“激活易下载”输入窗口。
2. 粘贴 5 组、每组 5 位的大写激活码，例如 `ABCDE-12345-FGHIJ-67890-KLMNO`。
3. 激活成功后，授权状态会显示到期时间。

兼容说明：程序会自动修复旧版保存的无效代理值；清空记录会同时移除成功和失败记录，并保留激活输入窗口与隐藏默认菜单。绿色版使用独立数据目录，不会继承其他版本的激活缓存。

本次内部测试批次是 10 个、每个 1 个月，仅用于验收，不代表今后每次启动都会自动生成激活码。正式发放由开发者在本地签发，再单独交付给用户。

### 开发者签发激活码

在开发机 PowerShell 中执行下面的命令。工具从 Windows 凭据管理器读取 `owner-developer-key`，不需要把 Developer Key 粘贴到命令行；`--months` 可使用 1、2、6、12、24 或 36。

```powershell
cd "D:\anzhuang\codex-work\tools\VideoGrab\easy-download"
python scripts\issue-easy-download-license.py `
  --months 1 `
  --count 1 `
  --out "D:\xiazai\MyDrivers\backup\easy-download-license-YYYYMMDD.txt" `
  --note "易下载客户或测试备注"
```

把 `YYYYMMDD` 换成当天日期；工具拒绝覆盖已有文件。文件中每行包含一枚激活码和开发者用的许可证 ID，许可证 ID 不需要发给用户。普通用户只需在软件右上角粘贴 5 组、每组 5 位的激活码。

## 3. 下载

1. 粘贴视频链接。
2. 选择清晰度或音频 MP3。
3. 可选择下载目录；代理默认读取 `http://127.0.0.1:7892`，不使用代理时清空即可。
4. 点击“开始下载”，任务状态会显示在下方。

### YouTube 下载失败排查

如果失败信息中出现 `ProxyError`、`undefined:80` 或 `Failed to resolve 'undefined'`，这是旧设置把代理保存成了文字 `undefined`。在“设置 → 网络代理”中填写 `http://127.0.0.1:7892`，打开“仅海外网站自动使用代理”，点击“保存网络设置”，然后重新下载。也可以清空代理地址后直连，但 YouTube 通常需要可用代理。

当前版本会在启动时自动修复这个旧值，不需要手动修改 `settings.json`。如果日志出现 `undefined:80`，优先检查代理模式和代理软件是否运行；JavaScript runtime 警告不一定是连接失败的原因。

### 清空下载记录

“下载任务”右上角的“清空记录”会删除已完成和失败的任务记录，但会保留正在下载或排队中的任务。清理只影响任务列表，不会删除已经下载到磁盘的视频文件。

### 绿色版交付

请把原始便携版 ZIP 发给用户，不要把已经激活并运行过的解压目录重新压缩发送。绿色版首次启动显示“未激活”是正常的；用户需要输入自己的激活码。

### 专业版功能（1.0.0）

专业版不再把功能拆成互相跳跃的页面，而是按“来源 → 队列 → 整理输出”完成一次工作流：

- **来源**：一次粘贴多条链接，或在已登记网站中按关键词搜索；搜索结果显示标题、网址和所属网站，勾选后加入队列。
- **队列**：每一项可以独立选择最佳画质、4K、1080p、720p或 MP3，以及 MP4/MKV/MP3 输出格式；可设置并发数和失败重试次数，确认后点击“开始全部下载”。
- **整理输出**：选择已完成文件，设置日期/标题命名、按网站/主题分类、保存原字幕、翻译目标语言，并选择“合并为独立字幕轨道（MKV）”或同时生成 SRT。
- **翻译服务**：默认使用免费公共翻译，不要求用户配置 Key；公共服务可能限流，译文请人工校对。对效果不满意时，可在设置中填写自己的 HTTPS OpenAI 兼容服务。
- **字幕轨道**：不重新压制画面，只把译文作为可切换的独立字幕轨道封装；当前支持 MP4、MKV、MOV，音频文件不能封装视频字幕轨道。

## 4. 浏览器扩展与登录状态

在 Chrome 加载易下载扩展后，已支持的网站会出现统一入口：

- 扩展点击弹窗：`下载当前视频`，或 `发送到易下载`。
- 页面空白处右键：`下载此视频`。
- 视频链接上右键：`下载此视频`。

“下载当前视频”会沿用软件中保存的画质、格式、目录和代理策略；“发送到易下载”只把链接填回首页，用户确认后再下载。软件未启动、页面不支持或 Chrome 尚未连接时，扩展会显示简短提示。扩展不监听剪贴板，也不创建系统托盘后台服务。

程序不会默认读取所有网站 Cookie。只有网站提示需要登录时，才在“设置 → 连接 Chrome 和网站登录状态”中点击“连接 Chrome”。程序会自动打开 Chrome 扩展页、连接向导和扩展文件夹；用户只需在 Chrome 中选择“加载已解压的扩展程序”，之后扩展会自动完成连接，不需要复制连接码或填写网站列表。扩展只会发现已登记平台且已获得浏览器权限的登录状态，并把域名加入网站列表；用户可以在易下载中删除不需要的网站。连接完成后回到下载任务重试。扩展会把列表中的登录状态发送到本机 `127.0.0.1:17893`，浏览器下载入口使用本机 `127.0.0.1:17894`。

自动发现不会申请全站权限，也不会在界面显示 Cookie 数量、名称或内容。没有获得浏览器权限的平台不会被扫描；如需新增平台，可以在扩展设置页手动添加域名并按 Chrome 提示授权。

Cookie 在本机使用 Windows DPAPI 加密保存，下载时只短暂解密到临时文件，任务结束后立即删除；不会上传到云端。

## 5. 更新

程序更新清单必须经过内置公钥签名，并校验 HTTPS 地址和 SHA-256。校验失败时不会替换现有程序。测试版如果显示“更新源尚未配置”，表示发行方还没有发布更新清单，不影响下载功能。

## 6. 问题反馈

反馈时请提供：软件版本、Windows 版本、页面提示文字和任务状态。不要发送激活码、Cookie 文件、`%LOCALAPPDATA%\\EasyDownload\\license.dat` 或 `cookies.dat`。

## 7. 公共服务与隐私说明

默认翻译会把字幕文本按小段发送到公共翻译接口；如果内容敏感，请不要使用公共翻译，改用本地工具或自定义、可信的服务。软件没有内置开发者个人 API Key，也不会要求普通用户配置 Key 才能使用默认翻译。

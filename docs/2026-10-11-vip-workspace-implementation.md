# 易下载 VIP 工作台实现记录

日期：2026-10-12

## 已实现

- 统一桌面壳层：`首页 / 下载任务 / 专业版 / 设置`。
- 首页保留免费单链接下载、保存目录、最近下载任务。
- VIP 宣传改为紧凑横幅，避免影响免费流程。
- 下载任务页提供运行中、等待中、完成、失败统计和失败诊断入口。
- 专业版工作台提供批量下载、关键词搜索、字幕与整理、项目规则四个子页签。
- 批量下载继续使用现有完整专业版授权和下载后端。
- 字幕翻译界面明确项目规则为可选项。
- 设置页包含下载目录、代理、浏览器登录同步、字幕服务、激活和更新。
- 字幕页已接入 SRT/VTT 提取、MyMemory 免费公共翻译、译文 SRT 保存，以及 MP4/MKV/MOV 的独立字幕轨道封装；自定义 OpenAI 兼容服务可在高级设置中本机加密保存。
- 关键词搜索已接入“登记网站过滤 → 结果列表 → 勾选 → 下载队列”流程；YouTube 使用 yt-dlp，哔哩哔哩使用公开站内接口，其他登记网站使用严格域名过滤的网页索引兜底。

## 当前边界

- 网页索引受搜索引擎收录、登录和限流影响；未收录的私密内容不会伪造结果。
- 字幕轨道封装不支持音频文件，且不会烧录画面；当前默认输出独立字幕轨道和 SRT 文件。
- 项目规则已经完成界面入口，自动套用到任务队列的逻辑尚未接入。
- 暂停/继续全部按钮保留入口，等待任务队列控制接口接入。

# 易下载用户操作手册

## 一、第一次使用

1. 打开易下载。
2. 在首页粘贴视频链接。
3. 选择画质、格式和保存目录。
4. 点击“开始下载”。

普通公开视频不需要连接 Chrome。只有页面提示“需要登录”、会员或年龄限制时，才需要连接浏览器登录状态。

## 二、两步连接 Chrome

### 第一步：在易下载点击“连接 Chrome”

打开“设置”，找到“连接 Chrome 和网站登录状态”，点击“连接 Chrome”。

程序会自动打开：

- Chrome 扩展管理页
- Chrome 连接向导页
- 易下载扩展文件夹

连接向导票据只在本机有效，10 分钟后过期。

### 第二步：在 Chrome 加载扩展

1. 在 `chrome://extensions` 页面打开右上角“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择易下载自动打开的 `extension` 文件夹。
4. 等待连接向导显示“已连接”。

完成后回到易下载即可。普通用户不需要复制连接码、不需要填写域名，也不会看到 Cookie 数量或内容。

如果之前安装过旧的“易下载浏览器下载”或“易下载浏览器连接”，请先在 Chrome 扩展页移除旧版本，再加载当前版本文件夹。

## 三、浏览器直接下载

扩展加载成功后，在 YouTube、抖音、B站等已支持网站上可以：

- 点击扩展图标，选择“下载当前视频”；
- 页面空白处右键，选择“下载此视频”；
- 视频链接上右键，选择“下载此视频”。

浏览器入口会沿用易下载中保存的画质、格式、保存目录和代理设置。软件需要保持运行；本版本不使用系统托盘后台服务。

## 四、代理设置

打开“设置 → 连接设置”：

- 点击“自动检测代理”，程序会检测常见的本机代理端口；
- 点击“直接连接”，使用当前网络直接访问；
- 如果你知道代理地址，可以展开高级设置手动填写。

代理是用户的网络偏好，不是程序故障。程序会在下载前显示当前使用的连接策略。

## 五、下载任务

打开“下载任务”可以查看：

- 正在下载的任务和进度；
- 已完成文件；
- 失败原因和重试按钮。

点击“清空记录”只会清除任务列表，不会删除已经下载的视频文件。

## 六、常见问题

### Chrome 没有自动打开

手动打开 Chrome，访问 `chrome://extensions`，然后点击“连接 Chrome”卡片中的“打开扩展文件夹”，再选择该文件夹加载。

### 连接向导显示已过期

回到易下载，点击“连接 Chrome”重新开始。每次连接都会生成一张新的短时票据。

### 浏览器提示需要登录

先在对应网站的 Chrome 页面完成登录，再重新点击“连接 Chrome”。连接成功后返回任务页重试下载。

### 浏览器右键没有“下载此视频”

确认加载的是当前版本 `extension` 文件夹，而不是旧扩展；然后在 `chrome://extensions` 点击扩展的刷新按钮。

## 七、隐私说明

- 普通公开视频不读取 Cookie。
- 只有用户主动连接 Chrome 后，程序才同步已登记网站的登录状态。
- Cookie 在本机使用 Windows DPAPI 加密保存。
- Cookie 不上传云端，也不会在界面显示内容。

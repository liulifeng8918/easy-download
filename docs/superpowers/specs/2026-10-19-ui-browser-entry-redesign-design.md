# 易下载浏览器入口与界面体验改造设计规格

日期：2026-10-19  
状态：已按确认规格实施并完成 0.1.10 回归  
适用版本：易下载多网站版

## 1. 改造目标

本次改造解决两个核心问题：

1. 用户在浏览器中看到视频时，可以在页面、视频链接或扩展弹窗直接进入下载，不必手动复制链接再切回软件。
2. 软件从“功能能用”升级为“主流程清楚”：免费用户只看到一条明确的下载路径，专业用户在“来源 → 队列 → 整理输出”中完成高级工作。

本次不改变授权模型、不移除现有下载引擎、不引入系统托盘常驻、不监听剪贴板。不同网站仍由各自解析策略处理，但共用同一套用户偏好和任务状态。

## 2. 视觉方向：云白蓝流线

### 2.1 色彩令牌

| 用途 | 颜色 | 说明 |
|---|---|---|
| 页面底色 | `#F6F9FC` | 取代大面积浅绿背景 |
| 主表面 | `#FFFFFF` | 主内容与表单表面 |
| 主色 | `#1976F3` | 主按钮、当前导航、进度 |
| 主色浅底 | `#EAF3FF` | 当前导航、提示、选中状态 |
| 辅助色 | `#42B9D6` | 浏览器入口、链接、信息提示 |
| 文字主色 | `#14233B` | 标题和主要内容 |
| 文字次色 | `#65748B` | 说明、辅助信息 |
| 成功 | `#16A46A` | 已完成、连接成功 |
| 警告 | `#D98A16` | 需要登录、需要代理、VIP提示 |
| 失败 | `#D64B4B` | 下载失败、输入错误 |

不得使用墨绿色作为品牌主色或主按钮色。边框使用 `#D9E3EF`，阴影只用于弹层和悬浮操作，避免每个区域都做卡片。

### 2.2 字体与布局

- 中文界面优先使用系统无衬线字体，正文 14–16px，标题 24–34px。
- 桌面默认内容宽度 1120–1280px，左侧导航固定 232px。
- 页面优先使用分组、留白和细分隔线；不使用卡片套卡片。
- 主按钮只保留一个视觉焦点；次要操作使用文字按钮或描边按钮。
- 统一四项侧边栏：`首页`、`下载任务`、`专业版`、`设置`。所有页面顺序、图标风格、选中状态一致。

## 3. 信息架构与核心流程

### 3.1 首页：单链接快速下载

首页只承担首次下载和偏好确认：

1. 顶部显示产品名和口号：`你浏览器能播放的，我们就能下载`。
2. 主输入框接受单个 URL、分享文案或带乱码的复制文本；前端先提取并归一化唯一视频地址。
3. 输入框下方使用一行四项偏好：`画质`、`格式`、`保存目录`、`代理策略`。
4. 主按钮为 `开始下载`。提交后立刻显示预检状态，不把技术错误直接暴露给用户。
5. 底部显示最近 1–3 个任务预览和 `查看全部`，避免首页变成完整任务管理页。
6. 专业版只显示一条紧凑浅蓝提示，不占用主要下载区域。

默认偏好：

- 画质：最佳画质
- 格式：MP4；选择音频画质时自动切换 MP3
- 保存目录：上次成功使用的目录，首次使用为系统视频目录下的 `EasyDownload`
- 代理：自动检测代理；国内网站默认直连，海外网站按域名策略使用代理

用户在首页临时修改的偏好只作用于当前任务；点击“设为默认”或在设置页保存后才改变长期默认值。

### 3.2 浏览器入口：直接下载与发送到软件

浏览器扩展只在识别到已登记且已支持的网站时显示下载入口。

扩展弹窗：

- `下载当前视频`：读取软件已保存的画质、格式、目录和代理策略，直接提交任务。
- `发送到易下载`：把归一化 URL 发送到软件首页，用户确认后开始下载。
- 显示当前连接状态和简短失败提示；软件未运行时提示“请先打开易下载”。

右键入口：

- 页面空白处：`下载此视频`
- 视频链接上：`下载此视频`
- 页面不属于已登记网站：不显示技术错误，只显示“暂不支持此网站”或不显示入口。

约束：

- 不监听剪贴板。
- 不创建系统托盘后台服务。
- 扩展只申请已登记平台和本机通信所需权限。
- 登录态仍由用户主动打开“连接浏览器”并同步；扩展不自动读取所有网站 Cookie。

### 3.3 下载任务页：按状态处理

任务页改为单一任务中心，顶部使用四个轻量状态筛选：`全部`、`进行中`、`已完成`、`失败`。

每项任务显示：标题、来源网站、画质/格式、进度、当前状态和下一步操作。

- 进行中：暂停、继续、取消
- 已完成：打开文件夹、复制文件路径
- 失败：短原因、`重试`、`打开设置`
- 顶部：暂停全部、继续全部、`清空记录`

“清空记录”只移除任务记录，不删除磁盘文件；进行中任务不被清理。

失败文案使用用户动作导向：

- 需要登录：`请在浏览器登录该网站，再打开设置 → 连接浏览器同步。`
- 需要代理：`该网站通常需要代理，请检查代理状态或切换直连。`
- 不支持：`暂不支持此网站，欢迎联系微信 open_java 评估适配。`
- 网络失败：`网络连接中断，可直接点击重试。`

### 3.4 专业版：来源 → 队列 → 整理输出

专业版不再使用互相跳跃的功能标签，固定为三步：

1. **来源**：多条链接粘贴、已登记网站关键词搜索、搜索结果勾选。
2. **队列**：逐项修改画质和格式，设置并发数、失败重试和保存目录，开始全部下载。
3. **整理输出**：选择完成文件，按日期/网站/标题命名，按网站或主题分类，保存字幕、翻译字幕并封装独立字幕轨道。

免费用户可以看到专业版入口和功能说明，但点击高级操作时只出现一次清晰的激活提示，不打断单链接下载。

### 3.5 设置页：常用设置优先，高级设置折叠

设置页分为四组：

1. **常用下载**：默认保存目录、默认画质、默认格式。
2. **网络连接**：自动检测代理、直接连接、高级代理地址。
3. **浏览器连接**：扩展目录、连接码、同步状态、已登记网站池。
4. **专业版与更新**：激活状态、版本、检查更新。

“域名、令牌、手动代理地址、翻译 API”等技术设置默认折叠，并在旁边提供一句通俗解释。普通用户不需要理解令牌或代理端口即可完成单链接下载。

## 4. 数据与交互规则

### 4.1 偏好存储

偏好由 Electron 渲染器通过现有侧车设置接口保存，字段统一为：

```text
quality: best | 2160 | 1080 | 720 | audio
format: mp4 | mkv | mp3
outputDir: absolute local path
proxyMode: auto | direct | manual
proxy: optional http(s) proxy URL
concurrency: 1..5
retryCount: 0..5
```

扩展只读取软件公开的偏好摘要，不读取许可证、Cookie 或本地文件内容。

### 4.2 URL 识别

- 优先识别当前页面的 canonical URL 和结构化视频 ID。
- 对抖音分享文案、小红书分享文案和带追踪参数的链接进行归一化。
- 解析失败时保留原始输入，并提示用户手动确认，不将错误 URL 直接交给下载引擎。
- 每个平台由站点适配器提供“识别、预检、登录/代理提示、下载参数”四个接口。

### 4.3 状态反馈

每个提交动作都先经过“识别中 → 预检 → 已加入任务/需要处理”的状态过渡。状态文字必须面向用户，不展示 `undefined:80`、内部异常堆栈或 Python 路由名称。

## 5. 分阶段实施计划

### 阶段 A：浏览器入口迁移

- 把 YouTube 分支的弹窗、页面右键、链接右键抽象为多网站入口。
- 接入当前网站识别和 URL 归一化。
- 统一“直接下载/发送到易下载”消息协议。
- 加入软件未启动、网站不支持、登录态缺失三种用户提示。

### 阶段 B：偏好与设置重构

- 统一画质、格式、保存目录、代理策略字段。
- 首页与扩展共用默认偏好。
- 设置页按常用/高级分组，保留旧配置兼容迁移。

### 阶段 C：界面体验重做

- 首页、任务页、专业版、设置页统一蓝色视觉令牌。
- 统一侧边栏、按钮、状态色、空状态和错误提示。
- 缩小专业版广告位，提升免费用户主流程的可见性。

### 阶段 D：专业版流程收敛

- 保持“来源 → 队列 → 整理输出”。
- 增加队列批量编辑、失败重试和输出规则预览。
- 让字幕翻译和独立字幕轨道在整理输出中完成，不新增跳转页面。

### 阶段 E：验收与发布

- Chrome 扩展弹窗、页面右键、链接右键逐个平台验证。
- 验证偏好从软件到扩展、从扩展到任务的传递。
- 验证登录态、代理直连/自动检测、失败重试和清空记录。
- 在 Windows 10/11 上分别做安装版和绿色版启动回归。
- 只在所有入口和失败提示通过后更新安装包与使用说明。

## 6. 验收标准

1. 新用户只看首页即可完成一次单链接下载，不需要进入设置。
2. 浏览器扩展能在已支持网站的弹窗、页面右键、视频链接右键发起下载。
3. 扩展直接下载使用软件最后保存的画质、格式、目录和代理策略。
4. 四个主页面的侧边栏、颜色、按钮和状态语义完全一致。
5. 免费用户不会被专业版大面积广告阻挡；单链接功能不因未激活而失效。
6. 失败消息能告诉用户下一步动作，且不泄露内部技术错误。
7. 设置页中高级技术项默认折叠，普通用户不需要配置令牌或代理地址。
8. 设计和实现均保留现有下载安全边界：不监听剪贴板、不上传 Cookie、不引入托盘常驻。

## 7. 明确不在本轮范围内

- 不承诺所有网站都能下载；不绕过 DRM、会员权限或访问控制。
- 不自动导入所有浏览器 Cookie。
- 不把翻译 API Key 写入扩展或上传云端。
- 不在本轮增加移动端、云端任务或系统级后台服务。

# 易下载：免费翻译与登记网站搜索设计规格

日期：2026-10-12  
范围：专业版字幕翻译、登记网站关键词搜索  
目标版本：0.1.x 增量开发

## 1. 用户体验目标

普通用户不需要填写任何翻译或搜索 API 配置即可使用默认功能：

1. 字幕翻译：选择视频、选择目标语言、点击翻译，软件自动使用内置的免费公共翻译服务。
2. 网站搜索：输入关键词，选择已经登记的网站，得到结果列表；结果显示标题、网址和所属网站，用户勾选后加入现有下载队列。
3. 默认服务失败、限流或效果不满意时，用户可以在高级设置中自行填写兼容 API；这属于可选项，不阻塞免费功能。

## 2. 凭据边界

- 不把任何个人 API Key 写入源码、安装包、日志、测试夹具或发布压缩包。
- 免费公共服务的“内置”只表示内置适配器、默认地址、限流和错误提示，不表示内置私人凭据。
- 自定义 API 由用户在本机配置；界面只显示已配置/未配置，不回显完整 Key。
- 发布前执行敏感信息扫描，确保构建产物中没有 `sk-`、Bearer Token 或测试密钥。

## 3. 翻译架构

### 3.1 Provider 接口

统一为：

```text
translateSegments(segments, sourceLanguage, targetLanguage, options)
  -> { translatedSegments, provider, warnings, usage }
```

Provider 必须支持：自动检测源语言、分段翻译、限流重试、部分失败、可取消和可审计错误信息。

### 3.2 默认公共 Provider

第一版默认使用无需用户 Key 的公共翻译服务适配器（当前验证可用的 MyMemory REST 接口）：

- 每段按服务限制拆分，避免超长字幕请求失败；
- 通过本地缓存避免重复请求；
- 429/5xx 使用指数退避，超过上限后转为明确的“公共服务暂时不可用”；
- 不把公共接口宣传为无限额度或稳定 SLA；
- 默认限制单个视频的字幕字符数和请求频率，保护用户体验与公共服务。

### 3.3 可选自定义 Provider

高级设置提供“自定义翻译 API”区：

- Provider 类型：OpenAI 兼容接口；
- Base URL、模型名、Key 均由用户填写；
- 默认不启用；启用后由用户选择“公共服务优先”或“自定义服务优先”；
- Key 使用 Windows 本机凭据/DPAPI 保存，前端不回显；
- 失败时可回退公共服务，但需要在结果中标明实际使用的 Provider。

Agnes 属于这一可选 Provider，不写入安装包。

### 3.4 字幕处理流程

```text
已下载视频
  -> 提取字幕（优先原字幕，缺失时提示暂不支持自动听写）
  -> 规范化 SRT/VTT 时间轴
  -> 选择目标语言
  -> 公共 Provider 翻译
  -> 可选自定义 Provider 重试
   -> 保存原字幕、译文字幕和处理报告
   -> 可选封装为独立字幕轨道（不重编码画面）
```

第一版不把语音识别伪装成“字幕提取”；没有现成字幕时明确提示后续能力。

## 4. 登记网站搜索架构

### 4.1 输入与范围

- 网站范围只取“域名池”中的登记域名；
- 用户可以在搜索面板勾选一个或多个登记网站；
- 所有返回结果必须再次校验 hostname 是否属于所选域名，防止第三方跳转污染结果。

### 4.2 搜索接口

统一为：

```text
searchRegisteredSites(keyword, domains, options)
  -> { results: [{ title, url, site, snippet }], warnings, provider }
```

### 4.3 Provider 顺序

1. 内置已验证站内搜索适配器：YouTube 使用 yt-dlp 搜索，哔哩哔哩使用公开站内接口。
2. 其他登记域名使用公开网页索引的 `site:` 查询作为兜底；结果标记为“网页索引”，并在返回后再次做域名过滤。
3. 网页索引被限流、没有收录或需要登录时，明确返回空结果/警告，不伪造结果，也不扩大到全网。

### 4.4 用户流程

```text
关键词
  -> 选择登记网站
  -> 搜索
  -> 结果列表（标题 / URL / 所属网站 / 摘要）
  -> 用户勾选
  -> 加入现有下载队列
```

搜索不会自动下载，也不会因为结果为空而自动扩大到全网。

## 5. 错误与提示

- 公共翻译限流：显示“公共翻译服务暂时繁忙，可稍后重试或配置自定义服务”。
- 公共翻译质量：显示实际 Provider 和“机器翻译，建议人工校对”。
- 字幕不存在：显示“该视频没有可提取字幕”，不显示“翻译失败”。
- 网站未登记：阻止搜索并提示先在“连接浏览器”中登记网站。
- 网站已登记但只有网页索引：显示“网页索引”来源；公开索引没有收录时显示原因。
- 搜索结果下载失败：沿用现有下载诊断，不把搜索失败误报为下载失败。

## 6. 测试与验收

### 翻译

- 公共 Provider 的正常响应、空响应、429、5xx、超长分段和部分失败；
- 中英文字幕至少各一组端到端测试；
- 自定义 Provider 未配置时默认流程可用；
- 自定义 Provider 配置后可切换并显示实际 Provider；
- 构建产物敏感信息扫描通过。

### 搜索

- 单域名、多域名搜索；
- 结果显示所属网站；
- 外部域名结果被过滤；
- 勾选结果准确加入下载队列；
- 未登记域名、网页索引限流和空结果均有明确提示；
- 无搜索 Key 时不伪造结果。

## 7. 明确不承诺

- 不承诺公共翻译接口无限额度、永久可用或质量等同商业翻译；
- 不承诺所有登记网站都有可调用的站内搜索；
- 不绕过登录、DRM、验证码或网站访问限制；
- 不把“支持搜索”表述为“全网搜索”。

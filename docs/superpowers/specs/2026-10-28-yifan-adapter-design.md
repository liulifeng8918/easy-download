# 易下载：爱壹帆公开视频适配设计

## 目标

让用户粘贴 `yifan.tv` 的公开视频播放页后，可以沿用易下载现有的画质、格式、目录、任务核验和错误提示流程完成下载。

## 支持边界

- 支持 `www.yifan.tv`、`yifan.tv`、`m.yifan.tv` 及 `iyf.tv` 的公开 `/watch?v=...` 播放页。
- 适配器只读取站点公开页面和其公开的 `MasterPlayList` HLS 接口。
- 不导入浏览器 Cookie，不绕过登录、验证码、访问限制或 DRM。
- 接口返回的签名媒体地址只在当前任务内存中使用，不写入任务历史、日志或设置。

## 架构与数据流

1. `link-input.cjs` 将爱壹帆域名标记为 `yifan-hls`，不再让通用 `yt-dlp` 直接解析原始页面。
2. `yifan-resolver.cjs` 从播放页 query 的 `v` 参数得到视频 ID，调用对应站点的 `upload.<站点主域>/api/video/MasterPlayList?id=...`。
3. 解析返回的 HLS 播放列表，验证响应是 M3U8，并通过现有公开 URL 校验；选取第一个有效播放列表地址。
4. `DownloadController` 将解析后的媒体地址、原始播放页作为 referer、当前 User-Agent 交给 Python 下载引擎；任务对用户仍显示原始页面地址。
5. 现有媒体核验负责确认输出包含可解码的视频和音频；失败时不标记为完成。

## 错误处理

- 原页面不是 `/watch` 或缺少 `v`：提示“请复制具体视频播放页地址”。
- 接口返回登录/验证/空播放列表：提示网站要求正常访问或当前视频不可用。
- 网络超时或接口不可达：提示检查网络/代理，不伪装成“未登录”。
- HLS 含 DRM 或非公开密钥保护：明确提示易下载不提供下载。

## 验收

- 单元测试覆盖域名识别、ID 提取、M3U8 解析、异常分类和媒体地址不落历史。
- 用用户给出的 URL 运行真实预检，并下载短片段验证 HLS、视频、音频和 FFmpeg 合并链路。
- 回归既有 Node/Python 测试，确保 YouTube、抖音和通用链接流程不受影响。

# 易下载：免费翻译与登记网站搜索实施计划

## 阶段 1：公共翻译适配器

1. 新增 Python `translation_service.py`，实现 MyMemory 公共 REST 调用、字幕分段、缓存、超时、429/5xx 退避和结构化错误。
2. 在 sidecar 增加 `/v1/subtitles/translate`，只接受结构化字幕片段、源语言、目标语言和服务模式；限制请求体、片段数和总字符数。
3. 增加 SRT/VTT 解析和重新渲染，保留时间轴、原文和译文文件。
4. 自定义 OpenAI 兼容 Provider 先做配置模型与本机 DPAPI 存储，不在默认流程中要求 Key；没有 Key 时公共 Provider 正常工作。

## 阶段 2：字幕页面接线

1. 页面从下载任务加载已完成视频，显示可处理任务。
2. 增加“提取字幕 / 翻译 / 保存 SRT / 封装独立字幕轨道”状态和错误提示。
3. 目标语言仍由用户选择；默认简体中文。
4. 明确区分“无字幕”“公共服务限流”“翻译失败”和“自定义服务未配置”。

## 阶段 3：已登记网站搜索

1. 新增 Python `search_service.py` 与统一 `searchRegisteredSites` 接口。
2. 实现 YouTube、Bilibili 站内搜索适配器；其他登记域名使用严格 `site:` 网页索引兜底，不伪造结果。
3. 所有结果通过域名池二次校验，并返回标题、网址、所属网站、摘要和搜索来源。
4. 页面增加网站多选、结果勾选、全选/取消全选、加入下载队列。
5. 保留通用搜索 Provider 配置入口，但没有 Key 时不自动扩大搜索范围。

## 阶段 4：测试与发布验收

1. Python 单元测试覆盖翻译分段、响应解析、缓存、退避、SRT/VTT、域名过滤和结果勾选数据。
2. Node UI smoke 覆盖字幕页面、搜索结果选择和下载队列提交。
3. 运行现有 Node/Python 全量测试、Electron UI smoke、目录打包 smoke。
4. 对源码、发布目录和安装包做敏感信息扫描；确认没有个人 Key、Bearer Token 或测试凭据。
5. 站内 API 和网页索引分别显示来源，并在发布说明中列出当前站点适配范围。

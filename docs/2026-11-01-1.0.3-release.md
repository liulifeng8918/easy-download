完整绿色 ZIP 不含任何个人设置、登录状态或激活信息；新解压目录与原目录是独立数据空间。请勿同时启动两份软件。

主 EXE、Node、yt-dlp、FFmpeg、Python 引擎与 1.0.2 保持相同二进制，不修改 Windows 安全设置。PDF 操作手册继续使用 1.0.2 图文版，操作步骤没有变化。

详细验证结果见同目录 `2026-11-01-1.0.3-acceptance.md`。网站、线路及账号状态可能变化，公开样例通过不等于承诺所有内容或所有画质可下载。

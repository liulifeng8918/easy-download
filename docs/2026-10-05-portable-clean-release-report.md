## 给用户的交付规则

只发送原始 ZIP。用户解压整个目录后双击 `启动易下载.cmd`。不要把已经激活过的目录重新打包给别人，否则可能把该目录中的本地授权缓存一起发送出去。

绿色版不绕过 Windows 安全策略；未签名程序仍可能被其他电脑的智能应用控制拦截。

# 易下载 VIP 能力升级提案

日期：2026-10-10  
定位：视频下载器，不扩展成泛素材管理平台

## 一、判断

“批量下载、字幕翻译、自动分类、失败重试”本身是功能名，不是用户愿意付费的结果。用户真正愿意付费的是：

- 更少等待和盯守：任务可以排队、暂停、继续并在失败后给出可执行原因；
- 下载后马上能用：视频、音频、字幕、封面和来源信息自动整理成一个素材包；
- 重复工作一次设置即可复用：命名、目录、代理、登录状态和画质规则按网站或项目保存；
- 难下载的网站有人负责评估和适配，而不是让用户自己研究代理、Cookie 和命令行。

因此 VIP 不应只增加“更多按钮”，而应交付“从链接到可用素材”的工作流。

## 二、推荐的能力层级

### P0：先做出明显的付费价值

1. **专业任务队列**：多链接、暂停/继续、并发数、断点续传、失败原因和一键重试。
2. **一键素材包**：同一链接可生成视频、音频、封面、字幕、描述/来源信息，并按同一任务归档。
3. **项目规则**：保存项目名称、目录、文件命名模板和默认画质；下次粘贴链接直接套用。
4. **可解释的失败诊断**：区分需要登录、需要代理、链接过期、平台暂未适配、DRM/权限限制，并给出下一步。

P0 的共同点是节省时间、减少重复操作，而且不依赖云端大模型，适合本地优先产品。

### P1：形成差异化

1. 播放列表、频道或账号批量（仅限平台允许且用户有权访问的内容）；
2. 按网站保存登录/代理配置，避免每次重新设置；
3. 下载结果去重、按日期/来源/项目归档；
4. 本地字幕提取和格式转换；翻译可先支持用户自带 API，避免把云端 AI 成本强行放进基础 VIP。

### P2：谨慎投入

- 在线 AI 总结、翻译和剪辑：有持续 API 成本，应单独计量或作为增值包；
- 云端同步和跨设备任务：会引入隐私、存储和售后成本，暂不作为第一版 VIP 核心；
- “去水印”：只针对用户拥有或获得授权的素材做后处理，不作为绕过平台限制的宣传点。

## 三、商业表达

免费版仍然是：单个链接、不限次数、完成核心下载闭环。  
VIP 版表达为：**“把一个链接变成一套可直接使用的素材，并让重复下载自动化。”**

特殊网站需求继续通过微信 `open_java` 联系，但只承诺评估链接类型、登录要求、地区限制、DRM 和技术可行性；定制支持不等于承诺所有网站都能下载。

## 四、落地顺序

当前 0.1.6 已落地专业版激活和批量下载入口；一键素材包、项目规则、任务队列和失败诊断先作为路线展示，避免把尚未完成的功能宣传成已交付。

下一版建议按以下顺序开发：

1. 任务队列和断点续传；
2. 一键素材包；
3. 项目规则与结果去重；
4. 网站级登录/代理配置；
5. 字幕与可选翻译服务。

每项上线前都用“免费用户首次下载成功率、VIP 功能点击率、重复使用率、平均排障时间”验证是否真的产生付费价值。

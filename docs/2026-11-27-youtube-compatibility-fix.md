# YouTube 兼容补丁（仅本机，2026-11-27）

## 根因

用户样例 `C9v5lIPG44o` 使用已同步的会话仍失败。旧 2026.10.26 引擎的播放脚本解析报 `a.addOnDisposeCallback is not a function`，只取得 storyboard，没有音视频流。预检查隐藏了警告，再将默认格式选择失败误报为“没有当前画质”；实际上预检查没有应用 720p 选择器。

## 修复范围

- 新增独立 `bin/yt-dlp-youtube.exe`，官方 2026.11.23 版本，校验上游 SHA-256。
- 仅精确匹配 youtube.com / youtu.be 及其子域使用新版；其它平台仍使用原 yt-dlp.exe，不改其解析器、代理策略或资源预算。
- 保留 YouTube 解析警告，优先区分脚本兼容失败与画质不可用，避免再次建议用户反复登录。
- 重建并核验冻结 Python 服务，确保不是只修改旁边的 Python 源文件。
- 更新前备份当前程序文件，保留设置、Cookie 和连接凭据；不修改 Windows 安全策略，不绕过验证码、DRM 或网站权限。

## 验证

- 新组件识别出该视频 144/240/360/480/720p；无解析警告。
- 通过实际 Electron → 冻结服务 → 专用解析器完成整段 720p 下载，约 17 秒；最终 MP4 为 24,363,846 字节，时长 296.79 秒，1280×720，包含音轨。
- 独立整段 FFmpeg 解码通过。
- 53 项 JavaScript、41 项 Python 测试通过；新增 YouTube 专用引擎路由隔离、相似恶意域名拒绝及错误分类测试。
- 隔离 Chromium 的实际扩展配对、模拟视频完整下载、手动深度检查和旧凭据拒绝回归通过。未重新对抖音或爱壹帆做真实网络整段下载，不宣称这些网站完成本轮实测。

该轮修复先应用于本机。随后用户明确要求同步 GitHub，将作为 1.0.4 发布；不覆盖既有 1.0.3。网站未来变化仍可能需要进一步维护。

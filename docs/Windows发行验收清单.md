# Windows 10 / Windows 11 发行验收清单

本机已完成：Python 引擎封装、安装包安装启动、Electron 与本机引擎健康联调、授权配置安全检查、Cookie DPAPI 存储测试、扩展脚本语法检查。

以下项目需要在干净的 Windows 10 和 Windows 11 机器上各执行一次，不能用本开发机结果替代：

- 安装 `EasyDownload-<版本>-x64.exe`，确认安装目录可更改、桌面快捷方式可启动。
- 首次启动不要求系统预装 Python；页面显示下载引擎已连接。
- 输入一枚未使用测试激活码，确认激活成功；重启后仍保持授权。
- 粘贴一个公开可下载链接，分别测试视频和 MP3；确认输出目录可选择。
- 添加一个网站、安装 Chrome 扩展、粘贴配对令牌；确认只推送已添加域名。
- 关闭程序后重新打开，确认下载任务、授权和 Cookie 配对状态没有导致启动失败。
- 在没有代理、代理不可用和代理可用三种情况下确认错误提示清晰。
- 点击检查更新：未配置更新源时显示“更新源尚未配置”，不能阻塞下载。
- 卸载后确认程序目录、快捷方式和卸载入口正常；按产品策略决定是否保留用户授权数据。

记录机器系统版本、安装结果、激活结果、下载结果和失败截图。只有两套系统均通过，才把安装包交给外部用户。

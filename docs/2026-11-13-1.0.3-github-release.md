# 易下载 1.0.3｜爱壹帆修复，免费版持续开源

易下载会持续维护更新，免费版源码持续开放。单个视频下载免费、不限次数，不需要激活码；专业版为可选功能。

## 本次修复

- 修复爱壹帆 `iyf.tv` / `yifan.tv` 新 `/play/` 地址被误报为无效地址的问题。
- 复制链接、浏览器扩展下载入口共用正常播放器适配；原 `watch?v=` 路线保留。
- 匹配当前视频编号和主播放器时长，避免下载成广告、其他剧集或单个分片。
- 保留 1.0.2 的 Chrome 图文连接、自适应下载资源预算、进度与声画检查。

## 选择下载文件

- **新用户**：下载 `EasyDownload-1.0.3-x64-portable.zip`，完整解压后双击 `易下载.exe`。
- **已有 1.0.1 / 1.0.2 用户**：先退出软件，将 `EasyDownload-1.0.3-update.zip` 中的 `resources` 合并到原绿色版目录。保留原有 `resources/app/user-data`，不需要重新连接 Chrome；不要删除整个原目录。
- **操作手册**：`EasyDownload-1.0.3-User-Manual.pdf`。沿用 1.0.2 图文手册，连接和下载步骤没有改变。
- 两个 ZIP 均提供对应 `.sha256` 校验文件。源码见本 Release 的 Source code，许可为 GPL-3.0-only。

# 易下载 1.0.2：连接引导与性能

## 本次变化

- 连接 Chrome 时打开图文向导，再自动将扩展管理页置前。软件设置也有截图、打开管理页和复制准确文件夹路径的按钮。首次仍需要自己开启开发者模式并确认加载，不需要填写连接码。
- 分片资源总预算按 CPU 和 Windows 可用内存取 1 / 2 / 4；同时下载任务共享预算，资源不足排队。异常网络请求可用单分片兼容策略重试一次，不擅自改代理。
- 复用同链接、画质、线路下 60 秒内的一次性解析结果；通过标准输入传递，不写媒体地址缓存文件。Windows 标准输入使用 ASCII JSON，保留中文标题。
- 经对照验证，抖音不启用 HTTP 分块；Eporner 可启用 1–4 MiB 分块，其他网站继续原生策略。HLS/DASH 并发与 HTTP 分块不是一回事，不宣称所有网站固定倍速。
- 任务显示速度、剩余时间、线路和分片上限。
- 默认检查容器、时长、声音和首尾短片段；完成项可手动执行整段“深度检查”。快速检查不能排除中段所有损坏，深度检查不修改文件。
- 新 PDF 手册为 `易下载用户操作手册-1.0.2.pdf`，软件内按钮打开新版。

## 升级

关闭易下载，将更新包的 resources 文件夹合并到原绿色版目录，覆盖同名程序文件，再打开原来的易下载.exe。保留原目录的 user-data；不要把用过的目录直接发给别人。更新不更换 Chrome 扩展，不重置连接、激活和下载设置。完整 ZIP 是未带任何个人数据的新用户包。

为保留已可运行的启动方式，主程序易下载.exe 与原 1.0.1 保持相同二进制；软件内版本由程序资源显示为 1.0.2。Windows 的文件属性可能仍显示旧壳版本。主 EXE 不变不代表保证每台 Windows 都不拦截，未改动系统安全设置。

## 验证边界

自动化使用 Windows 本机、隔离测试目录，不修改用户 Chrome 配置。低/中/高资源阈值用模拟测试覆盖，不等同于三台真实配置电脑或 Win10/Win11 双系统验收。完整下载、浏览器扩展、快速/深度检查和打包校验的最终结果记录在同目录的验收报告中。

# 易下载 1.0.2：持续更新，免费版持续开源

易下载会持续更新维护，并持续公开免费版源码。**单个视频下载持续免费、不限次数，不需要激活码。** 推出可选专业版不会取消免费版的基础下载能力。欢迎放心使用免费版、检查源码、提交问题与改进建议。

## 下载哪个文件？

- 新用户：`EasyDownload-1.0.2-x64-portable.zip`，解压整个文件夹，双击 `易下载.exe`。不需要另外安装 Python、Node.js 或 Electron。
- 已有 1.0.1 用户：`EasyDownload-1.0.2-update.zip`。先退出软件，再把 `resources` 合并到原目录，保留 `user-data`。原目录升级不重置已有 Chrome 连接和设置。
- PDF：`EasyDownload-1.0.2-User-Manual.pdf`（中文手册），从解压到 Chrome 连接、下载完成的图文操作步骤。软件内和源码目录中的原文件名为“易下载用户操作手册-1.0.2.pdf”。
- `.sha256`：对应 ZIP 的校验文件。

本次发布的是绿色免安装版，不是旧版安装器。不要同时运行多个版本。

## 本次更新

1. Chrome 图文向导直达扩展管理页，明确标出开发者模式和加载按钮，可一键复制准确文件夹路径。
2. 按 CPU 与可用内存分配 1 / 2 / 4 份共享分片预算，多任务不会各自开满；基础性能优化对免费版同样开放。
3. 复用短期解析结果，显示速度、剩余时间和线路；适用站点采用分块/分片优化，不强行改变用户代理设置。
4. 默认快速检查首尾声画，另提供手动深度检查，减少整段解码等待。
5. 修复抖音不兼容编码选择、重复下载误报，以及 Windows 中文标题问题。

## 验证与边界

- 39 项 Python、47 项 JavaScript 测试通过；Chrome 入口、启动与重启、真实完整视频下载回归通过。
- 当前本机的单次样例：YouTube 约 32 MB / 24 秒，抖音约 9.7 MB / 8 秒，另一个约 109 MB 的样例约 57 秒。不同时间和线路会变化，不承诺固定加速倍数。
- 硬件阈值已做模拟测试，尚未在多台低配实体电脑及 Win10/Win11 双系统上完成实测。
- 快速检查不能排除视频中段所有损坏，可手动执行深度检查。
- 不绕过网站人机验证、付费访问权限或 DRM。请只下载拥有版权、获得授权或平台明确允许下载的内容。
- 官方 ZIP 不带个人 Cookie、激活码或开发者密钥。使用后的个人目录不要直接转发给别人。
- 本版本未购买 Windows 代码签名证书，部分系统仍可能提示未知发布者或拦截；请核对官方来源，不要关闭系统安全防护。

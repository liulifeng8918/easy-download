# 易下载 1.0.1 修复与回归记录

日期：2026-10-31。此记录区分代码检查、实际下载和仍未通过的项目；不以“能启动”代替全部验收。

## 为什么新增网站后，原有功能也出现问题

不是一个“新增网站适配器直接改坏全部平台”的单点问题。本轮确认存在发布流程和公共链路缺陷，过去的验收没有覆盖到：

1. **源码与实际执行的引擎不一致**：旧包内 Python 源文件已经更新，但实际运行的 `runtime/easy_download_sidecar.exe` 仍是 10 月 24 日编译的版本。仅检查随包 `.py` 文件不能证明修复已进入 EXE。
2. **代理设置在解析后丢失**：普通网站预检沿用已保存的代理，实际创建下载任务时却被覆盖为空。现已统一保存策略。
3. **Chrome 配对过早报成功**：旧流程在发出连接凭据时就标记成功，没有等扩展确认收到；切换绿色版目录又可能使原连接失效。现改为扩展保存后认证确认，下载前检查当前连接。
4. **抖音首页与播放器兼容缺口**：浏览器首页地址不是当前视频地址；部分播放器使用 blob，旧逻辑无法取得对应媒体；另外播放器已经可播放时，页面其他资源仍可能未加载完。
5. **下载进度被隐藏**：获取最终文件路径的引擎参数隐式进入安静模式，旧版本没有显式恢复进度输出，造成“像卡住”的体验。
6. **随机启动失败**：base64url 随机会话凭据可能以 `-` 开头，原命令行分开传入 `--token` 和值，Python 会误当作选项。现用 `--token=值` 的无歧义形式，并覆盖特殊开头的回归测试。

这些是程序和交付验证的问题，不应反复要求用户重新登录来掩盖。

## 本轮修复

- 构建前强制重新编译 Python EXE，并检查 EXE 内嵌代码中的 HLS、进度和会话适配逻辑；启动时核对引擎版本。
- Chrome 连接采用新确认协议；旧扩展不能再产生虚假的配对成功。未过期向导可安全重试，避免扩展加载/刷新中断确认；失效连接显示重新连接提示。
- 扩展下载前同步用户已允许的网站登录状态；不会读取未授权平台的 Cookie，不记录 Cookie 内容。
- 抖音工具栏入口识别当前活动视频；明确的视频页/分享页不再依赖尚未注入的页面脚本，避免按钮误禁用。blob 媒体仅接受带有**同一目标视频编号**的已观察播放请求，不猜测推荐视频。
- 抖音内置浏览器只复用用户已主动同步给易下载的抖音会话，不直接读取 Chrome 数据库。
- 不要求页面所有资源加载完成后才检查视频；加载较慢时显示等待提示，解析等待有上限。
- 浏览器提交链接后立即确认“已交给软件”，后续解析进度和失败原因显示在软件，不让扩展长时间等待解析结果。
- 保留实际下载的代理策略；恢复百分比、速度、剩余时间和分片进度；爱壹帆保留四分片并发、有限重试和失败退出。
- 修复 4K 选项校验、MP3 格式归一化、批量任务指定目录传递和独立字幕轨道临时文件后缀。
- YouTube 的“网站人机验证”与“未登录”分开提示，不再把所有访问限制误导成登录问题。
- 下载引擎更新至官方 `2026.10.26`，下载后核对官方发布资产 SHA-256：`f5389d3698ecde4ef06f4e6b1ce0294fe9ac1396228c8990b8d3416d6d177a7d`。[官方发行记录](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26)

## 验证范围与限制

- 37 项 JavaScript 测试、32 项 Python 测试通过。
- 打包后的真实 Electron 界面覆盖：免费单条入口、VIP 拦截、激活输入框、设置保存、Chrome 认证确认、目录选择 IPC、浏览器发链接、页面跳转、窄窗口、退出和重启。未消费新的生产激活码。
- 扩展集成使用独立 Chromium 测试配置，不修改用户现有 Chrome 扩展。测试的是实际扩展弹窗 HTML 的按钮，不把无头浏览器测试冒充物理工具栏气泡点击。
- 下载成功必须生成非空媒体文件，并通过 FFmpeg 完整解码；不只看预检、退出码或“100%”。
- 实测系统为 Windows 11 专业版 x64，版本 10.0.26200；本轮没有 Windows 10 虚拟机，不能宣称跨 Win10/Win11 全部验证。

### 未通过或未实测

- **YouTube：当前网络请求返回 `Sign in to confirm you're not a bot`。** 干净环境和复用用户此前已授权同步的 YouTube 登录态均未通过；更新引擎后仍未通过。网站要求的正常验证不能由本软件承诺跳过。当前包不应被描述为“YouTube 已验收通过”。
- 小红书、TikTok、Facebook、Instagram、X、西瓜等本轮没有逐个平台的当前账号样例验收。保留现有实现不等于它们已经实测通过。
- VIP 生产激活、搜索结果质量、公共翻译服务可用性、批量并发和自动重试的完整付费工作流，不在本轮已通过的真实外网验收范围。字幕轨道封装另有合成视频的实际 FFmpeg 测试，不代表所有平台都有可提取字幕。
- 安装包构建和运行载荷验证不等于在全新 Windows 上完成安装/卸载验收。未签名程序仍可能受 Windows 安全策略限制；软件没有修改或绕过安全策略。

## 升级与分发

1. 关闭所有旧版易下载，只运行一个版本；将新 ZIP 完整解压到新文件夹，直接双击“易下载.exe”。
2. 在 Chrome 中停用旧版“易下载”扩展副本，加载 **1.0.1** 包内的 `resources/app/extension` 文件夹。
3. 在软件设置中重新点击“连接 Chrome”，完成一次连接。切换绿色版目录会更换本地连接身份，不能保证沿用旧连接。
4. 扩展更新后刷新已打开的抖音网页，再使用“下载当前视频”。
5. 发给别人时使用原始 ZIP，不能压缩自己用过的绿色版文件夹；使用后的 `resources/app/user-data` 含个人设置和登录状态。

本轮只生成本地修复包，不自动覆盖公开发布版本。鉴于 YouTube 仍未通过当前网络验收，发布说明必须保留这一限制。

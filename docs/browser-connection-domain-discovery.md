# 浏览器连接与平台域名发现

## 用户可见命名

- 扩展名称：易下载浏览器连接
- 主程序入口：连接浏览器
- 主程序按钮：复制连接码
- 扩展操作：保存并同步登录状态

“Cookie Bridge”“配对令牌”“推送”等实现术语不再出现在用户界面中；内部接口名称可以保持不变，避免影响已有版本。

## 隐私边界

扩展不会导入或展示浏览器中的全部 Cookie，也不会向云端上传 Cookie。扩展只在本机、用户已授予访问权限的范围内调用浏览器 Cookie API，并把必要的登录状态发送给本机易下载进程。

## 已登记平台自动发现

扩展启动、打开设置页或执行同步时，会依次检查已登记平台域名是否存在可用登录状态。检查结果只保留域名，不保存 Cookie 数量、名称、值或内容到设置页面。发现的平台会自动加入“网站列表”，用户可以直接删除不需要的平台。

自动发现不会申请全站权限。没有获得浏览器权限的平台不会被扫描；用户仍可在列表中手动添加平台，Chrome 会按站点请求权限。这样保持最小权限和原有隐私边界。

## 兼容行为

已有扩展的本地存储字段、连接码和本机接口保持兼容。扩展版本升至 1.2.0；重新加载当前扩展文件夹即可使用新名称和新发现逻辑。

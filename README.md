# 易下载（Easy Download）

易下载是一个 Windows 本地视频下载工具：粘贴链接，或在 Chrome 页面右键发送到易下载，选择画质、格式和保存目录后下载。

当前正式版本：**1.0.3** · Windows x64 · GPLv3

## 持续更新，免费版持续开源

**易下载会持续更新维护，并持续公开免费版源码。单个视频下载持续免费、不限次数，不需要激活码。**

推出专业版不会取消免费版的基础下载能力。欢迎大家放心使用免费版、检查源码，并通过 Issues 反馈问题、提出建议；欢迎开发者参与改进。

开源不意味着所有网站、所有链接永远可下载：网站规则、网络线路和登录要求可能变化，我们会持续跟进修复，并如实说明支持边界。

## 下载使用

新用户下载绿色版 ZIP，解压整个文件夹后双击 `易下载.exe`，不需要另外安装 Python、Node.js 或 Electron。请勿只复制其中的 EXE。

已有 1.0.1 / 1.0.2 用户：先退出软件，再把更新包的 `resources` 文件夹合并到原来的绿色版目录；保留原目录的 `user-data`，以保留设置和 Chrome 连接。不要同时运行两个版本。

单个链接下载免费；批量下载、字幕处理、自动整理等专业工作流需要专业版激活码。

当前已验证的特殊站点路线还包括爱壹帆（`yifan.tv` / `iyf.tv`）公开播放页。网站要求验证时，由用户在正常网站窗口完成；不绕过验证码、DRM 或付费权限。

## Chrome 连接

只有网站提示需要登录时才需要连接 Chrome：

1. 在易下载设置中点击“连接 Chrome”。
2. 程序会打开 Chrome 扩展管理页和图文向导。先开启右上角“开发者模式”，再点击左上角“加载已解压的扩展程序”（部分版本叫“加载未打包的扩展程序”）。
3. 点击“复制扩展文件夹路径”，在选择窗口按 `Ctrl + L`、`Ctrl + V`、回车，然后点击“选择文件夹”。
4. 等待显示“已连接”，回到易下载重试。

连接码会自动处理，不需要新手自己填写。首次加载扩展仍需用户确认，不静默安装、不修改 Chrome 安全策略。完整步骤见软件设置中的 PDF 手册和 [新版图文手册](docs/易下载用户操作手册-1.0.2.pdf)。

## 隐私与安全

- 官方分发的原始 ZIP 不带个人登录状态、Cookie、激活码或开发者密钥。
- 浏览器登录状态仅在用户授权范围内用于本机下载，本地加密保存，不上传至云端授权服务。
- 视频下载会访问对应网站；字幕翻译等联网功能会请求相应服务。专业版激活会访问授权服务。这不等于软件完全离线运行。
- 本版本没有购买 Windows 代码签名证书，个别系统可能提示未知发布者或阻止运行；请核对下载来源和 SHA-256，不要为此关闭系统安全防护。
- 使用过的绿色版目录会产生个人数据。给他人分发时请使用 Releases 原始 ZIP，不要直接打包自己的使用目录。
